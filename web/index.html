Time Lock

Locks a random code until a time you choose. The code is encrypted to a future round of the drand network, and the key for that round doesn't exist until drand publishes it. Nothing can open a lock early, including you.

This browser isn't keeping data for this page, so locks are only kept until you close it. Download every lock file.

  1. Create a lock. The page makes a random code you've never seen.
  2. Save the lock file, then set the code as your Screen Time passcode (or password).
  3. Come back after the time is up and open the lock to get the code.
